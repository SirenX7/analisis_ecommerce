# Análisis de datos de e-commerce

## Objetivo

Analizar el comportamiento de las ventas y los clientes para identificar
patrones relevantes en el desempeño comercial y el comportamiento de compra.

Idioma: Los valores modificados o incorporados durante el proceso de limpieza se presentan en español, como decisión de presentación orientada al público hispanohablante. Los nombres originales de las columnas se conservan cuando resulta conveniente.
