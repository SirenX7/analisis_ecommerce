# Análisis de datos de e-commerce

## Objetivo

Analizar el comportamiento de las ventas y los clientes para identificar patrones relevantes en el desempeño comercial y el comportamiento de compra.

## Proceso

El proyecto incluye:

- Exploración y comprensión de los datos.
- Análisis y tratamiento de valores faltantes.
- Validación de la calidad de los datos.
- Transformación y creación de nuevas variables.
- Definición y resolución de preguntas de negocio.
- Visualización e interpretación de resultados.

## Herramientas

- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Jupyter Notebook
- Git / GitHub

## Análisis

Se analizaron aspectos relacionados con:

- Ventas y rentabilidad.
- Clientes.
- Marketing y campañas.
- Comportamiento temporal.
- Distribución geográfica.
- Envíos y devoluciones.
- Satisfacción de los clientes.

## Consideraciones

Los valores modificados o incorporados durante el proceso de limpieza y transformación se presentan principalmente en español. Los nombres originales de las columnas se conservan cuando resulta conveniente para mantener la trazabilidad con el dataset original.

Las métricas monetarias se analizaron considerando la moneda correspondiente, evitando comparar directamente valores expresados en diferentes divisas.
